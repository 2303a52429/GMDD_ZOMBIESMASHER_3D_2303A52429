# Vyshnavi Vallala | Portfolio

Personal portfolio website: plain HTML and CSS, no build step. Featured project: **Zombie Smasher 3D** (Unity 6 URP zombie runner).

## Publish on GitHub Pages (5 minutes)

1. On GitHub, create a **new public repository** named exactly `YOUR-GITHUB-USERNAME.github.io`
   (for example `vyshnavivallala.github.io`). This gives you the address `https://YOUR-GITHUB-USERNAME.github.io`.
2. Click **"uploading an existing file"**, drag in **everything inside this folder**
   (`index.html`, `style.css`, `README.md` and the `assets` folder), and click **Commit changes**.
   `index.html` must be at the top level of the repository, not inside another folder.
3. Go to **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**,
   Branch **main**, folder **/ (root)**, and click **Save**.
4. Wait 1 to 2 minutes, then open `https://YOUR-GITHUB-USERNAME.github.io`.

## Before you publish: fill in your links

Open `index.html` and replace every placeholder that starts with `YOUR-`:

| Placeholder | Replace with |
|---|---|
| `YOUR-GITHUB-USERNAME` | your GitHub username |
| `YOUR-LINKEDIN-ID` | the end of your LinkedIn profile URL |
| `YOUR-EMAIL@example.com` | your email address |
| `zombie-smasher-3d` repo link | your Zombie Smasher 3D repository |
| `YOUR-DEMO-VIDEO-LINK` | a YouTube / Drive link to the gameplay video |
| `YOUR-EEG-REPO`, `YOUR-MEDICAL-IMAGING-REPO`, `YOUR-RADIOML-REPO` | your project repositories |

Also add your resume as **`resume.pdf`** next to `index.html` so the "Download resume" button works.

## Adding a new project

Copy one `<article class="card"> ... </article>` block in the **Projects** section of `index.html`
and change the emoji, title, bullet points, tags and link.
